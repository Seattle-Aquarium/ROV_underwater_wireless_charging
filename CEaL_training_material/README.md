## Seattle Aquarium ROV operator training

### Overview 
This folder contains links, files, and resources necessary for Conservation Engagement and Learning (CEaL) personnel and other Seattle Aquarium staff to prepare for ROV flight operations off Pier 59.

ROV pilot training will be facilitated via completing some basic reading and homework ahead of time: 

- For a high level view of the system you will operate -- please review [ROV control system overview](https://github.com/Seattle-Aquarium/ROV_underwater_wireless_charging/blob/main/CEaL_training_material/ROV_control_system_overview.md).
- You will want to understand the hardware available on the ROV -- please review Hardware 
- You will need to aquant yourself with the general steps required for the various operations associated with the ROV -- please review Protocols. 
- Blue Robotics (BR) has fantastic documentation and user guides. 
Learn more about Blue Robotics [here](https://bluerobotics.com/), the BlueROV2 [here](https://bluerobotics.com/store/rov/bluerov2/), and see basic stats about the BlueROV2 via the datasheet [here](https://github.com/Seattle-Aquarium/ROV_underwater_wireless_charging/blob/main/CEaL_training_material/BlueROV2_datasheet.pdf).
- ROV pilots will be required to power the ROV via the battery, which itself requires opening the battery enclosure and ensuring the two o-rings are properly greased and in good condition, and closing the ROV battery enclosure and visually ensuring the o-rings are properly seated. You can find detailed instructions include visuals [here](https://bluerobotics.com/learn/bluerov2-operation/#turning-the-bluerov2-on-and-off) on the Blue Robotics website
- See the BR guide [here](https://bluerobotics.com/learn/bluerov2-operation/#turning-the-bluerov2-on-and-off) regarding some basic ROV operational guidance, including the need to NOT let the battery voltage drop below **12.5V** -- **the battery will be damaged if it drops beneath 12.0V**.
